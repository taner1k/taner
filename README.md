функциональные требования к цифровой платформе (веб/мобильное приложение) для организации, проведения и анализа сравнительных тест-драйвов мотоциклов. Если нужен документ под офлайн-мероприятие или под конкретную CRM — структуру можно адаптировать.

Обозначения приоритетов:

Must — обязательно для MVP

Should — важно, но можно во второй версии

Could — опционально

1. Роли пользователей
Гость — просмотр каталога и публичных мероприятий.

Участник — запись на тест-драйв, сравнение, оценка мотоциклов.

Инструктор — сопровождение заездов, чек-ин, фиксация условий.

Организатор/Администратор — управление событиями, слотами, маршрутами, пользователями.
